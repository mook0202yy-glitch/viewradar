# 뷰레이더 (ViewRadar)

키워드로 유튜브 영상·채널을 찾고 **기여도 · 성과도 · 노출확률**로 비교하는 유튜브 트렌드 분석 웹사이트입니다.

**바로 쓰기:** https://mook0202yy-glitch.github.io/viewradar/

## 실행 방법

빌드가 필요 없는 정적 사이트입니다. 위 주소로 바로 쓰거나 내려받아 실행합니다.

1. `index.html`을 Chrome으로 엽니다(더블클릭).
2. 처음에는 **데모 모드**(가상 데이터)로 모든 화면을 체험할 수 있습니다.
3. 오른쪽 위 ⚙ **설정**에 YouTube Data API 키를 넣으면 실제 데이터로 분석합니다.

파일을 직접 열었을 때 API 호출이 막히면 폴더에서 로컬 서버로 띄우세요.

```bash
npx serve .
```

## YouTube API 키 발급 (무료)

1. https://console.cloud.google.com 에서 프로젝트를 만듭니다.
2. ‘API 및 서비스 → 라이브러리’에서 **YouTube Data API v3**를 사용 설정합니다.
3. ‘사용자 인증 정보 → API 키 만들기’ → 생성된 키를 설정 창에 붙여 넣고 **연결 테스트** → **저장**.

기본 할당량은 하루 10,000유닛입니다. 영상 검색 1회(50개)는 약 102유닛이므로 하루 약 90회 검색할 수 있습니다. 핫 비디오와 채널 분석은 회당 2~5유닛만 씁니다.
키는 브라우저 localStorage에만 저장되고 googleapis.com 호출에만 쓰입니다. 코드나 저장소에는 키가 들어가지 않습니다.
키가 남에게 쓰이지 않도록 Cloud Console의 키 설정에서 **애플리케이션 제한사항 → 웹사이트**를 고르고, 쓰는 주소만 허용해 두세요. 예: `https://mook0202yy-glitch.github.io/*`, `http://localhost:5173/*`. 이렇게 제한하면 `index.html`을 파일로 직접 열었을 때는 키가 동작하지 않습니다.

| 영상 찾기 | 키워드 검색(관련도/조회수/최신 정렬, 기간·길이 필터), 핫 비디오(국가별 인기 급상승), 상세 필터(조회수·구독자 범위, 등급), 추천 키워드, 표/카드 보기, `123` 수치 보기, CSV 내보내기 |

## 지표 정의

모든 지표는 YouTube API가 공개하는 수치만으로 계산합니다(`js/metrics.js`).

| 지표 | 계산 | 등급 기준 (Worst / Bad / Normal / Good / Great) |
| --- | --- | --- |
| 기여도 | 조회수 ÷ 채널 구독자 수 | <0.08 / ≥0.08 / ≥0.25 / ≥0.8 / ≥2.0 |
| 성과도 | 조회수 ÷ 채널 영상당 평균 조회수(총 조회수 ÷ 영상 수) | <0.3 / ≥0.3 / ≥0.7 / ≥1.8 / ≥4.0 |
| 노출확률 | 일평균 조회 속도를 채널 기준 속도(평균 조회수 ÷ 30일)와 비교한 모멘텀 × 경과일 감쇠 → 0~100% | 낮음 <40 / 보통 40~69 / 높음 ≥70 |

노출확률은 추정치입니다. API 모드에서 같은 영상을 20분 이상 간격으로 다시 조회하면 그 사이 **실측 증가량**을 반영해 보정합니다.
임계값은 `js/metrics.js` 상단에서 바꿀 수 있습니다.
